Research, Value Addition and Beneficiation

Mandate

To coordinate mineral value addition, beneficiation and processing research, and regulate value addition facilities.

Key functions

  • Coordinate mineral value addition, beneficiation and processing research projects.
  • Consolidate and analyse mineral production statistics.
  • Regulate and monitor mineral value addition plants and related facilities.
  • Promote technologies that improve production efficiency and reduce environmental hazards (e.g. mercury abatement).
  • Develop and recommend mineral value addition policies and investment opportunities.
